Troubleshooting

No hunt is starting

Check the grace period and cooldown, whether you are underground/asleep/in dialogue, and whether you are near a friendly or neutral base. Check that Prepare for uninstall is off. A hunt or following squad already pending prevents another ordinary hunt from starting.

Debug mode changes these conditions and timings; it is off by default. Use Debug logs to investigate ordinary play rather than assuming silence means the mod is broken.

A named hunter died instead of retreating

Verify both the modded executable and its matching scripts, including conflict winners. The required callback support dates from 15 September 2026. Updating the executable without restoring the correct scripts can leave ballistics protection unavailable.

Confirm the NPC type: regular squadmates and bosses are meant to be killable. See Hunters and squads.

A body vanished

An uncredited NPC kill normally teleports away. Named hunters do not leave ordinary lootable bodies, and a still-cloaked death can disappear to avoid an invisible corpse. See Loot and rewards.

A player assist has a short two-second window. If you are unsure whether the kill was credited, report the encounter with logs.

A message or cloak is missing

Check PDA settings, optional UI integrations and the invisible-model requirement. Turn up the relevant sound/effect setting before treating an absent cue as a failure.

Recognising log lines

Message Meaning
NEMESIS IMPORTANT ERROR (please report) Report it with both logs; it can indicate an install or lasting-state problem.
xlibs requirement / mod off Check xlibs installation, version and conflicts.
Missing squad section Check Nemesis configuration files and conflict resolution.
release guard (expected) Can be normal guarded squad cleanup; this line alone is not a broken hunt.
Member-unregistered line when quitting Can be normal level unloading; timing matters.

Reporting a problem

  1. Enable Debug logs in MCM → Nemesis Spawn System → Debug & tools.
  2. Reproduce the problem if possible.
  3. Send both appdata/logs/nemesis.log and appdata/logs/xray_<name>.log.
  4. Include the Nemesis version/package, modpack, engine build, xlibs version and what happened.
  5. Mention a recent load/map change, the boss or hunt involved, and any crash report.

Important errors can appear even with Debug logs off. Ordinary diagnostics need it enabled. Player and commented-source packages can have different script line numbers, so include the exact package name.

See Installation and updating and Uninstalling before changing versions or removing an active encounter.
