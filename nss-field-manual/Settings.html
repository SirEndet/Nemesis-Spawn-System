Reading the values

This manual lists the current defaults for version 1.0.3. Existing saves can retain different values. Ordinary option edits use MCM's normal application behaviour; preset selection is special because it applies immediately.

Day/hour labels on hunt scheduling refer to in-game time. Short combat, warning and cast delays described in seconds refer to encounter timing. Follow the units printed beside an option rather than treating every number as real hours.

Percentages can mean different things. Thunder regeneration is based on full health, his bolt damage on current health, and an anti-psy item's Mark effect removes a share of the current Mark. Each system's page explains its unit.

Debug mode and Debug logs are off by default.
