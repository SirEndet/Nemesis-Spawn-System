Installation and updating

Choose a package

Package Contents
NemesisSpawnSystem_1.0.3.zip The lighter player package, with explanatory script comments removed.
NemesisSpawnSystem_1.0.3-dev.zip The installable commented-source package.

Both packages provide the same gameplay. Choose one; you do not need both enabled.

Update the modded exes first

  1. Close the game. Open the latest official modded-exes release and download the packaged ZIP for your engine variant (standard or MT).
  2. Extract the complete archive into your Anomaly game folder, alongside AnomalyLauncher.exe. Merge the archive's folders into the matching folders there.
  3. Install both the executables and the included db folder. Copying only the .exe files is not enough: the engine's matching scripts are included in the archive too.
  4. Clear the shader cache through the Anomaly launcher once before the first launch with the updated engine.
Folder in the engine ZIP Destination
bin/ Anomaly/bin/
db/ Anomaly/db/, including its contents under db/mods/
Any other included folders The matching locations inside the Anomaly game folder.

Here, Anomaly/ means your game installation directory, not a folder inside the Nemesis mod. The ZIP's db folder goes directly into that game directory. Follow the official engine installation instructions for the full package.

Install with Mod Organizer 2

  1. Install the chosen ZIP as a mod.
  2. Enable Nemesis and the required xlibs dependency.
  3. Start the game and find MCM → Nemesis Spawn System.

Release archives contain gamedata/ at their root. For a manual installation, merge that directory into the game installation.

See Getting started for requirements and Compatibility for optional integrations. The exact name or enabled state of xlibs in a modpack can vary; verify it in your own mod list.

Updating an existing game

Update between hunts. Do not update while a hunt is active, while a following squad is pending, or while the Emission Boss is on his way. Finish the encounter and save first.

In Mod Organizer, install version 1.0.3 over the existing mod and choose Replace. Existing saves and saved settings carry over when updating in the supported state. The current defaults do not automatically replace your custom settings.

To apply the current 1.0.3 preset balance, select Medium under Difficulty. Presets apply immediately; read the backup behaviour before switching.

Removing the mod

Use the uninstall procedure, especially if the save has contained an active Nemesis encounter. Removing the files alone does not remove custom squads from an active-hunt save.
